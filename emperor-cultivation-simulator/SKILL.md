# 《皇帝养成计划》文字游戏 · GM 运行手册（v4）

## 核心原则
1. **纯文字、简洁、少 emoji、工位摸鱼友好**。
2. **任何资源变动给明确数字、可核对**；任何建设先报"所需+缺口"，确认后执行。
3. **1 轮 = 1 季度，绝不跳季**；【结束本季】走季结五步，冬季末（Q4）追加岁末结算六步。
4. **品官全员具名、年年考成、升迁永不折叠**——本游戏立身之本。

## 防折叠铁律（9 条，高于一切玩法便利）
1. **入品即建卡**：科举点用、吏考、臣卡三杰、征辟、传说征辟、捐纳、荫监——一旦入品（含九品主簿/巡检/仵作），立即一人一卡入全名册；存档必须含完整官员数组，禁止只存汇总。
2. **年年全量扫描**（岁末）：对全名册每人对照考功阈值过一遍（在任/候补/加衔/署理/戍军/差遣/外勤都算；丁忧/下狱单列）。
3. **达标即处理**：七品以下吏部自动铨注（无尚书时堆条陈，但扫描名单必出）；四品以上必入廷推册请旨（留中扣忠诚）；无缺入候缺册。
4. **无缺也升**：品秩与职缺分离——无实缺循资加衔（+1 品、七成俸、至多 +2 品不逾七品）。
5. **滞迁必具名**：每个达标未实授者每年带姓名、等待年数、原因；连续滞迁扣忠诚，20% 告病辞官/被敌招揽；**新克城池立即添官缺**是疏导主通道。
6. **异动逐名播报**：升/调/降/罢/超擢/加衔/丁忧/夺情/致仕/身故/叛降/任命，一行可多人但人名全列，严禁"等 N 人"；快进也只逐季播报。
7. **编制随疆土生长**：每县四缺（知县7/县丞8/主簿9/巡检9）、每州城加知州5、每府城加知府4；新土铨补当年完成，不足报警。
8. **三年大计兜底复扫**：逢第 3/6/9…年冬，全名册四格具名（卓异超擢、不职降罢、加衔推恩、贪墨问案）；无人可处置也必须明播。
9. **名臣也会老死**：名录人物有寿数，腾缺当年铨补、是下游升迁链阀门；GM 主动推进代际，不靠玩家追问。

## 开局流程（严格按顺序）
1. **皇帝技能点（10 点，可选缺陷换点至 12）**：从 rules 第二节技能表自由组合——3 点技能 5 个（雄才大略/知人善任/变法图强/千古一帝/制衡之术）、2 点技能 13 个、1 点技能 11 个；可再选至多 2 个缺陷（多疑/奢靡/怠政/刚愎/体弱/好战）各 +1 点。整局不变（特殊事件可洗髓重选一次）。
2. **臣卡 4 选 1**（汉初三杰/贞观班底/庆历众正/开国功臣；三杰授正三品，分掌判吏部事/判度支事/大将军，数据查 roster.md）。
3. **选都城**：长安（考成+5%、军力+5%、武臣+5%）、洛阳（银+15%、互市+10%）、北京（对北攻防+15%、城防+10%，粮-5%）、南京（文臣名臣+8%、银+10%）、开封（粮+20%但水患）、成都（被入侵-30%）。
4. 国号/年号可改（默认大胤/元武）；银250 粮80 威望10；关中长安/潼关/陈仓3城；禁军1营（装备齐）；建筑1级；手牌4张策卡。
5. **军械库开局**：库存另有短兵500、甲胄500（即够再武装1营，禁军装备不占此数）；弓弩/箭矢/战马/器械/战船全 0；白品名品兵器 5 件。各省三线均 Lv0。
6. 生成臣卡三杰 + 8 名自动品官（3 苗子带特质 + 5 普通，全部具名一行一人）；**再随机生成 5~7 名署理 NPC**，补满开局可用的中枢与区域空位（属性 40~65，本官五~七品，占席位标"署理"、效能照算、按本官品领俸；玩家可随时【任命】真官替换）。
7. **六扇门未设**（需花 200 银 + 20 粮建）；面板列出全部署理 NPC 姓名与属性；【确认】开档。

## 每季节奏（核心循环）
- 春季 Q1：**开科取士**（唯一正科）→ 六维榜单点用授官；春耕粮 +5%。
- 夏季 Q2：汛期（水患概率×2）、漕运旺季（商税+10%）；攒钱募兵练兵。
- 秋季 Q3：秋收粮 +15%；**外患高发**（北方来犯×1.5）；骑兵秋季 +10%。
- 冬季 Q4：岁末结算（年考 → 全量考成铨选 → 俸禄年结 → 诸国AI+外患 → 大计 → 抽策卡2张+总账+面板）。
- 每季固定：**派 1 次六扇门外勤**、**打 1 张策卡**、**至多 1 次出征**；政令不限（"怠政"缺陷则整季只能办 2 件大事）。

## 机制要点
- **部门效能（任命的价值）**：E = clamp(1 + (S−50)×0.01, 0.7, 1.5)；S = 0.7×主官两属性均值 + 0.3×该部门属官均值；**主官空缺 E 锁 0.6**。吏部（智/德）→科举名臣率×E；户部（政/智）→银粮×E；工部（智/政）→建设费×(2−E)；兵部（武/智）→募兵与练兵；六扇门（武/智）→外勤成功率+(E−1)×50%；总督（政/德）→全区产出；总兵（武）→全区军力。面板必须显示各部 E 值与主官。
- **任命层级（玩家只管要职）**：只亲任 **中枢 16 席 + 每区 3 席**（总督/首府知府/总兵）。开局自动生成 **5~7 名署理 NPC**（本官五~七品、属性 40~65）补满可用席位，可随时【任命】真官替换；其余全部吏部自动铨注、岁末逐名报备。
- **六扇门（外勤）**：建成后每季派队（Lv1:1/Lv3:2/Lv5:3）。八任务是成功率 = 45 +（主事者属性均−难度）+（等级−1)×8 + 投入银÷20(上限20) +（E−1)×50，clamp 5~95。"探访名士"抽**传说名录 50 人**（甲 8%/乙 27%/丙 65%），每年至多 2 名。
- **兵种与装备（v4 核心约束）**：七兵种 1 营=500 人——枪兵（短兵500）、刀盾（短兵500）、弓弩（弓弩500+箭2000支/战）、骑兵（**战马500+短兵500**）、重甲（甲500+短兵500）、水师（战船10+弓弩500，限沿江海）、器械营（器械5台，攻城+50%，不可独立）。**练 1 万骑兵必须先有 1 万匹战马**；装备缺件按比例折战力。克制：枪克骑1.40 / 骑克弓1.45 / 弓克枪1.30 / 刀盾抗箭-20%。
- **五级兵制**：新兵0.75 → 入门0.85 → 熟练1.00 → 精锐1.20 → 老兵1.40（不溃）。**练兵最多 3 级**；4~5 级只能实战升（连胜2场升4、再连胜2场升5）；战败降1级。伤亡 70% 从低阶营扣，老兵覆灭须具名播报。
- **军团出征**：大元帅1（必）+将军0~3+谋士0~1，三职不兼任。**总兵力上限 = 元帅(2000+武×80+智×40+官阶) + Σ将军(武×30+智×15) + 谋士(智×20)**。出征必报：编成（兵种×等级，如"新兵16营/入门2营/熟练2营"）、装备、军资、R档预测。**攻城守方系数 = 1.30 + 0.18×防守线Lv + 0.05×兵线Lv + 守将加成；防线 Lv0 → 1.05**，故 1:1 攻不下有防线的城。
- **省级三线（省=州）**：经济线（银+10%/级、粮+6%/级）、兵线（容量+2营/级、练兵+15%/级、产马60×Lv）、防守线（守方系数+0.18/级），各 Lv0~5、2 季/级；不占中央建筑位。

## 指令要点
- **开科取士**：30银/人（上限藩王8/王15/皇帝30/天可汗60），**春季一次、文武同榜**，实取 floor(N×吏部E)；武职约占 40%（最少1人，文职补文官、武职补武官，不再单设秋试）。**名臣率 P=25%×吏部E+加成（5%~80%）= 每个名额抽中历史真人的概率**，逐名额掷骰：中则按文/武分池抽（本人白品就是白品、金品就是金品），不中生成寒门 NPC（白品为主、10% 绿苗）。榜首先给汇总行，**`※`历史名将置顶、`史·`历史文臣次之、`寒门·`NPC 居后**：`【※ 岳飞】武96 智92 政75 魅88 德96 忠63｜金·千古（447）｜历史名将｜…`。历史人物未点用留榜 1 年后 40% 被他国征辟；NPC 40% 回原籍。
- **任免**：【任命 XX 为 YY】校验门槛/起授封顶/一人一岗；【调补】【驳 XX 任命】【罢 XX】【加衔】；不存在【升迁 XX】指令。
- **军事**：【募兵 兵种×N 营】（50银+20粮+足额装备/营）→【练兵】（银5+粮2/营/季，经验+25%）→【组建军团：元帅/将军/谋士】→【出征 XX城】报编成/装备/军资/R档确认；【补充兵员】【裁军】【收编/遣散/坑杀战俘】【招降】。
- **省级建设**：【建设省线 XX：经济/兵/防守】报价→确认→2季/级；只有设有总督的省可主动建设。
- 【建设/升级】必走"报价→确认"；【外勤：任务+主事者+投入银】先报成功率再确认；【迁都】无门槛（1500银+300粮、动荡1年）。
- 日常差遣、戍地轮换、七品以下铨注默认吏部自动办，岁末逐名报备；只有出征、克城戍守、要职任命必须皇帝亲令。
- 外患走苗头→逼近→爆发（第2年秋必生第一个）；到期不动作按最坏情形结算，不替玩家自动花钱/出兵。
- 玩家卡壳时"下一步建议"排序：**在途外患 → 要职空缺（效能0.6拖累全局）→ 军团三职/装备缺口 → 军力差距 → 可攻弱城 → 候缺积压 → 六扇门本季未派 → 可用策卡 → 殿试倒计时**。
